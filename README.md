# Система учета туристических путевок

Консольное приложение для туристического агентства: ведение каталога туров, учет клиентов, бронирование и оплата путевок.

## Описание предметной области

Туристическое агентство продает путевки (туры). У каждого тура есть стоимость, даты начала и окончания и **количество свободных мест**. Клиент выбирает тур, бронирует его и оплачивает со своего баланса. Менеджер подтверждает брони и оформляет продажу, а администратор управляет каталогом туров и учетными записями.

## Цели системы

- автоматизировать бронирование и продажу путевок;
- хранить каталог туров и следить за наличием мест;
- вести историю бронирований каждого клиента;
- разграничить доступ сотрудников и клиентов по ролям.

## Роли пользователей

| Роль | Что может делать |
|------|------------------|
| **Клиент** | регистрация, вход, просмотр каталога, выбор и бронирование тура, пополнение баланса, оплата, просмотр своих броней |
| **Менеджер** | вход, подтверждение брони, оформление продажи, просмотр всех броней |
| **Администратор** | вход, управление турами (добавление, изменение, удаление), управление пользователями |

## Архитектура и технологии

- **Язык программирования:** [Python 3](https://www.python.org/)
- **База данных:** [SQLite](https://www.sqlite.org/) (модуль `sqlite3` из стандартной библиотеки)
- **Диаграммы:** [PlantUML](https://plantuml.com/)
- **Архитектура:** многослойная (*Layered Architecture*):
  1. *Presentation Layer* — консольное меню;
  2. *Business Logic Layer* — проверки и правила (бронирование, оплата, роли);
  3. *Data Layer* — работа с базой данных SQLite.

## База данных (ЛР №3)

Проект использует реляционную базу данных **SQLite**. Скрипт создания: [schema.sql](schema.sql).

| Таблица | Назначение | Связи |
|---------|------------|-------|
| `UserRole` | справочник ролей (Клиент, Менеджер, Администратор) | 1:N с `User` |
| `BookingStatus` | справочник статусов брони (Создана, Оплачена, Подтверждена, Отменена) | 1:N с `Booking` |
| `User` | учетные записи: логин, хеш пароля, ФИО, телефон, роль, баланс | N:1 с `UserRole` |
| `Tour` | каталог туров: название, стоимость, даты, количество мест, доступность | 1:N с `Booking` |
| `Booking` | бронирования, связывают пользователей и туры (**многие-ко-многим**) | N:1 с `User`, `Tour`, `BookingStatus` |

   ```bash

   ```
3. Запустите приложение:
   ```bash

   ```
